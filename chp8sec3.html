    Lesson 7.3 \(LU\)-Decompositions

    Continuing with the core concept of the previous section, what happens when you can row reduce \(A\) to an upper triangular matrix \(U\) using only type 3 elementary row operations, only clearing downward. As I will show in a moment, this gives rise to a new type of decomposition.
    🔗

    Definition 7.3.1. \(LU\)-Decomposition.

    If \(A\) is a square matrix, then an \(LU\)-decomposition of \(A\) is an expression \(A=LU\) where \(L\) is a lower triangular matrix and \(U\) is an upper triangular matrix.
    🔗
    🔗
    Note that in the definition, neither the diagonals of \(L\) nor \(U\) need to be just 1’s.
    🔗
    I will first explain a method to find an \(LU\)-decomposition, tweaking the ideas behind finding an elementary matrix decomposition, and using the following simple proposition.
    🔗

    Proposition 7.3.2. Product of Lower Triangular Matrices is Lower Triangular.

    If \(L_1\) and \(L_2\) are lower (resp. upper) \(n\times n\) matrices, then their product \(L_1L_2\) is lower (resp. upper) triangular.
    🔗
    🔗

    Proof.

    In class activity. Hint: use Matrix Multiplication Meaning #1 and reason about about mixing vectors with many zeros.
    🔗
    🔗

    Remark 7.3.3. Construction: \(LU\)-Decompositions.

    If \(A\) can row reduced to an upper triangular matrix \(U\) using only type 3 row operations clearing below, then to construct an \(LU\)-decomposition:
    🔗
    1. Row reduce \(A\) to an upper triangular matrix \(U\) using only type 3 row operations clearing below.
      🔗
      🔗
    2. Record these row operations as elementary matrices. Observe that type 3 elementary matrices that clear below are lower triangular. We then get \(L_r\cdots L_2L_1A=U\text{.}\)
      🔗
      🔗
    3. Then, Socks and Shoes these matrices over to get \(A=L_1^{-1}\cdots L_r^{-1}U\text{.}\)
      🔗
      🔗
    4. Multiply together the \(L_i\)’s, and by Proposition Proposition 7.3.2, this product, \(L\) is lower triangular. We then have \(A=LU\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Activity 7.3.4.

    Compute an \(LU\)-decomposition for each of the following:
    \begin{equation*} \begin{bmatrix}1\amp 1\amp 1\\1\amp 2\amp 2\\1\amp 2\amp 3\end{bmatrix} \hspace{2pc} \begin{bmatrix}1\amp 2\amp 4\\3\amp 7\amp 15\\2\amp 8\amp 21\end{bmatrix} \hspace{2pc} \begin{bmatrix}0\amp 2\amp 9\\4\amp 3\amp 7\\2\amp 1\amp 2\end{bmatrix} \end{equation*}
    🔗
    🔗
    This idea is simple, but writing down and then multiplying each \(L_i\)’s for large matrices can be a pain. For the \(L_i\) that arise in this way, their product is nice as I shall now discuss.
    🔗
    Consider \(3\times 3\) case interpreted as a sequence of row operations performed to \(I\text{:}\)
    \begin{equation*} \underbrace{\begin{bmatrix}1\amp 0\amp 0\\c_1\amp 1\amp 0\\0\amp 0\amp 1\end{bmatrix}}_{L_1^{-1}} \underbrace{\begin{bmatrix}1\amp 0\amp 0\\0\amp 1\amp 0\\c_2\amp 0\amp 1\end{bmatrix}}_{L_2^{-1}} \underbrace{\begin{bmatrix}1\amp 0\amp 0\\0\amp 1\amp 0\\0\amp c_3\amp 1\end{bmatrix}}_{L_3^{-1}} \underbrace{\begin{bmatrix}1\amp 0\amp 0\\0\amp 1\amp 0\\0\amp 0\amp 1\end{bmatrix}}_{I}. \end{equation*}
    What we will be doing in filling up the columns of \(I\) below the diagonal, moving right to left. More precisely, it says, look at the second from the last column. Use the leading 1 to fill the column below it, filling from bottom to top. Then move one column to the left and repeat. When viewed this way, it is not hard to see that the product is then \(\begin{bmatrix}1\amp 0\amp 0\\c_1\amp 1\amp 0\\c_2\amp c_3\amp 1\end{bmatrix}\text{.}\)
    🔗
    In fact, this generalizes to \(n\times n\) matrices. This is formalized in the so called, Doolittle Algorithm.
    🔗

    Algorithm 7.3.5. Doolittle Algorithm for \(LU\)-Decompositions.

    If \(A\) can be row reduced to an upper triangular matrix \(U\) using only type 3 row operations clearing below and \(c_{ij}\) is negative the multiplier to use the pivot in the \(j^{\text{th}}\) row to clear the entry in the \(i^{\text{th}}\) row, then
    \begin{equation*} A=\begin{bmatrix}1\amp 0 \amp \cdots \amp 0\\ c_{21} \amp 1 \amp \cdots \amp 0\\ \vdots \amp \amp \ddots \amp \vdots \\ c_{n1} \amp c_{n2} \amp \cdots \amp 1\end{bmatrix} U. \end{equation*}
    🔗
    🔗
    Note that just as not all matrices may be reduced to an upper triangular matrix using only type 3 row operations only ever clearing below, it is also that case that not all matrices admit an \(LU\)-decomposition.
    🔗
    Unfortunately at this time, GeoGebra does not compute \(LU\)-decompositions, however, more powerful Computer Algebra Systems (CAS) can, such as the Python-based Sage. As such, I expect you should be able to compute \(LU\)-decompositions for \(2\times 2\) and \(3\times 3\) by hand. If you are so inclined, try out using Sage.
    🔗
    I expect that you understand the concepts behind where an \(LU\)-decomposition comes from, and why it works, so that you can alter the construction as necessary to create similar, related decompositions such as:
    🔗
    • \(PLU\)-decomposition where \(P\) is a permutation matrix, \(L\) is lower triangular, and \(U\) is upper triangular.
      🔗
      🔗
    • \(LDU\)-decomposition where \(L\) is unipotent lower triangular, \(D\) is diagonal, and \(U\) is unipotent upper triangular.
      🔗
      🔗
    🔗
    Suppose we have a matrix equation \(A\vect{x}=\vect{b}\) where \(A\) is square matrix with \(LU\)-decomposition \(A=LU\text{.}\) In these special situations, then to find \(\vect{x}\) we can use the \(LU\)-decomposition.
    🔗
    Since \(A\vect{x}=L(U\vect{x})\text{,}\) we may split the matrix equation \(A\vect{x}=\vect{b}\) into two simpler equations:
    \begin{equation*} \end{equation*}
    and we solve the first by forward substitution and the second by backward substitution.
    🔗
    Given the matrix equation \(L\vect{y}=\vect{b}\text{,}\) forward substitution is the recursive process of solving for \(y_i\) by substituting in the values \(y_1, y_2, \ldots, y_{i-1}\) into row \(i\) of the matrix equation.
    🔗

    Example 7.3.6.

    Suppose we have the matrix equation \(\begin{bmatrix}1\amp 0\amp 0\\1\amp 1\amp 0\\1\amp 1\amp 1\end{bmatrix}\begin{bmatrix}y_1\\y_2\\y_3\end{bmatrix}=\begin{bmatrix}3\\5\\6\end{bmatrix}\text{.}\) The forward substitution process proceeds as follows, one row at a time:
    🔗
    1. The first row tells us that \(y_1=3.\)
      🔗
      🔗
    2. Next substitute \(y_1\) into row 2, getting: \(y_2=5-y_1=5-3=2.\)
      🔗
      🔗
    3. Lastly, substitute \(y_1\) and \(y_2\) into row 3, getting \(y_3=6-y_1-y_2=6-3-2=1.\)
      🔗
      🔗
    🔗
    🔗
    Backwards substitution is the analogous recursive process for matrix equations \(U\vect{x}=\vect{y}\) in which you solve for \(x_i\) by substituting in the values \(x_{i+1}, x_{i+2}, \ldots, x_n\) into row \(i\) of the matrix equation.
    🔗
    When dealing with large matrices, this process can be relatively fast for solving matrix equations as compared to other methods for solving matrix equations.
    🔗
