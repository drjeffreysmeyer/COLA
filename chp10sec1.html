    Lesson 9.1 Concepts of Invariant Lines

    Processes are everywhere. We want to develop a deep understanding of processes. Chaining together processes gave rise to the notion of composition. Reversing a process gave rise to the notion of inverses. Our next fundamental idea associated to a process is invariance.
    🔗
    The the core idea of invariance is that something does not change after having performed a process. Rotations in the plane do not change length. Length is an invariant of rotation. Shears in the plane do not change area. Area is an invariant of shears.
    🔗
    Recall that if \(L\subset \R^n\) is a line and \(T:\R^n\to \R^n\) is a matrix transformation, then \(T(L)\) is also a line (Proposition 3.3.7). We will now compare the lines \(L\) and \(T(L)\text{.}\) Might there be some lines for which \(L\) and \(T(L)\) are the same?
    🔗

    Definition 9.1.1. Invariant Lines.

    If \(T:\R^n\to \R^n\) is a matrix transformation with associated matrix \(A\text{,}\) then a line \(L\) through the origin (a.k.a. a 1-dimensional subspace) is \(T\)-invariant (or \(A\)-invariant) if it is sent into itself under the transformation. Symbolically, \(T(L)\subset L\text{.}\) When \(T\) is clear from context, we will usually drop reference to \(A\) or \(T\) and just say the line is invariant.
    🔗
    🔗
    Write the line \(L=\{t\vect{x} \ | \ t\in \R\}\) in parametric vector form (Definition 2.3.8) for some nonzero vector \(\vect{x}\in L\text{.}\) If \(L\) is \(T\)-invariant, then \(T\) must send \(\vect{x}\) to some other point on the line, i.e. \(T(\vect{x})=\lambda \vect{x}\) for some \(\lambda\in \R\text{.}\) It follows from the scaling property if matrix multiplication (Proposition 3.1.13),that \(T\) then scales each point on the line by this same \(\lambda\text{.}\)
    🔗

    Definition 9.1.2. Associated Scaling Factor.

    If \(T:\R^n\to \R^n\) is a matrix transformation and \(L=\spn(\vect{x})\) is a \(T\)-invariant line, then the value \(\lambda\in \R\) for which \(T(\vect{x})=\lambda \vect{x}\) is the associated scaling factor.
    🔗
    🔗
    Understanding \(T\)-invariant lines and their associated scaling factors gives us an incredible about of information about \(T\text{.}\)
    🔗

    Activity 9.1.4. Using SMD to find invariant Lines.

    If you have a nice similar matrix decomposition, you can quickly read off its invariant lines. For each of the following matrices, determine its invariant lines and associated scaling factors.
    🔗
    \begin{equation*} A=\left[ \begin{array}{rr}1 \amp -1 \\ 1 \amp 1 \end{array}\right]\left[ \begin{array}{rr}2 \amp 0 \\ 0 \amp 3 \end{array}\right]\left[ \begin{array}{rr}1 \amp -1 \\ 1 \amp 1 \end{array}\right]^{-1} \hspace{2pc} B=\left[ \begin{array}{rr}3 \amp 1 \\ 1 \amp 2 \end{array}\right]\left[ \begin{array}{rr}1 \amp 1 \\ 0 \amp 1 \end{array}\right]\left[ \begin{array}{rr}3 \amp 1 \\ 1 \amp 2 \end{array}\right]^{-1} \end{equation*}
    \begin{equation*} C=\left[ \begin{array}{rr}2 \amp -1 \\ 1 \amp 2 \end{array}\right]\left[ \begin{array}{rr}1 \amp 0 \\ 0 \amp 0 \end{array}\right]\left[ \begin{array}{rr}2 \amp -1 \\ 1 \amp 2 \end{array}\right]^{-1} \hspace{2pc} D=\left[ \begin{array}{rr}3 \amp 1 \\ 1 \amp 2 \end{array}\right]\left[ \begin{array}{rr}0 \amp -1 \\ 1 \amp 0 \end{array}\right]\left[ \begin{array}{rr}3 \amp 1 \\ 1 \amp 2 \end{array}\right]^{-1} \end{equation*}
    🔗
    In fact, this is more generally true. Try to use Definition Definition 9.1.1 to justify each of the following propositions.
    🔗

    Proposition 9.1.5. Invariant Lines and SMDs.

    If \(\mathcal{B}= \{\vect{v}_1,\ldots, \vect{v}_n\}\subset \R^n\) is a basis, \(P=[\vect{v}_1|\cdots| \vect{v}_n]\text{,}\) \(D\) is a diagonal matrix with diagonal entries \(\lambda_1,\ldots, \lambda_n\text{,}\) and \(A=PDP^{-1}\text{,}\) then for each \(i\text{,}\) \(1\le i\le n\text{,}\) the line \(L_i = \{t \vect{v}_i \ | \ t\in \mathbb{R}\}\) is an \(A\)-invariant line with scaling factor \(\lambda_i\text{.}\)
    🔗
    🔗

    Proof.

    It suffices to show that \(A\vect{v}_i=\lambda_i\vect{v}_i\text{.}\)
    🔗
    \begin{equation*} A\vect{v}_i =P(D(P^{-1}\vect{v}_i))=P(D\vect{e}_i)=P(\lambda_i\vect{e}_i)=\lambda_i(P\vect{e}_i)=\lambda_i\vect{v}_i. \end{equation*}
    🔗

    Definition 9.1.6. Invariant Subspaces.

    If \(T:\R^n\to \R^n\) is a matrix transformation with associated matrix \(A\text{,}\) then a subspace \(W\subset \R^n\) is \(T\)-invariant (or \(A\)-invariant) if \(T(W)\subset W\text{.}\)
    🔗
    🔗
    We may generalize Proposition 9.1.5 to any \(T\)-invariant subspace.
    🔗
    Invariant Subspaces and SMDs If \(W\) is an invariant subspace of \(B\) and \(A=PBP^{-1}\text{,}\) then \(P(W)\) is an invariant subspace of \(A\text{.}\)
    🔗

    Example 9.1.7.

    Suppose that \(S=\{\vect{v}_1,\vect{v}_2,\vect{v}_3\}\subset \R^3\) is an ordered basis. The \(3\times 3\) matrix
    🔗
    \begin{equation*} A=[\vect{v}_1,\vect{v}_2,\vect{v}_3]\begin{bmatrix}2 \amp 0 \amp 0 \\ 0 \amp 0 \amp -1 \\ 0 \amp 1 \amp 0\end{bmatrix}[\vect{v}_1,\vect{v}_2,\vect{v}_3]^{-1}. \end{equation*}
    We can see two invariant subspaces. The line \(L=\spn(\vect{v}_1)\) is \(A\)-invariant with scaling factor 2. The plane \(W=\spn(\vect{v}_2,\vect{v}_3)\) is invariant and \(T_A\) acts upon it by a rotation of \(90^\circ\) \(\vect{v}_2\) towards \(\vect{v}_3\text{.}\)
