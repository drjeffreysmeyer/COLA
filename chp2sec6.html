    Lesson 2.6 Subsets That Contain Their Mixtures

    Lesson Subsets That Contain Their Mixtures

    The algebraic properties of span in Proposition 2.4.8 and null space in Proposition 2.5.17 are rather important. Mixture is the fundamental operation of linear algebra, and spans and null spaces have the property that a mixture of elements within the set always stays within the set. It is useful for us to identify and name this special property for when we encounter it again.
    🔗

    Definition 2.6.1. Subspace.

    If \(W\subset \R^m\) is a subset that satisfies the following three properties:
    🔗
    1. Contains Zero. If \(\vect{0}\in \R^m\) denotes the zero vector, then \(\vect{0}\in W\text{,}\)
      🔗
      🔗
    2. Closed Under Addition. If \(\vect{u},\vect{w}\in W\text{,}\) then \(\vect{u}+\vect{w}\in W\text{,}\)
      🔗
      🔗
    3. Closed Under Scaling. If \(\vect{w}\in W\) and \(k\in \R\text{,}\) then \(k\vect{w}\in W\text{,}\)
      🔗
      🔗
    then \(W\) is a subspace.
    🔗
    🔗
    Subspaces are subsets which contain their mixtures. Such subsets are at the heart of linear algebra.
    🔗
    Observe that the whole space, \(\R^m\text{,}\) and the zero subset, \(\{\vect{0}\}\) satisfy these properties, and hence are subspaces. A consequence of Proposition 2.4.8 is that spans are always subspaces.
    🔗

    Proposition 2.6.2. Spans are Subspaces.

    If \(S\subset \R^m\) and \(W=\spn(S)\text{,}\) then \(W\) is a subspace in \(\R^m\text{.}\)
    🔗
    🔗

    Proposition 2.6.3. Null Spaces are Subspaces.

    If \(S\subset \R^m\) is a set of \(n\) vectors and \(W=\Null(S)\text{,}\) then \(W\) is a subspace in \(\R^n\text{.}\)
    🔗
    🔗
    When we view vectors geometrically, it is often useful to re-interpret the three properties of Definition 2.6.1 in the following geometric way.
    🔗

    Insight 2.6.4. Subspace — Geometric Formulation.

    If \(W\subset \R^m\) is a subspace, then:
    🔗
    1. Origin Containment. The origin is contained in \(W\text{.}\)
      🔗
      🔗
    2. Parallelogram Containment. If \(\vect{v},\vect{w}\in W\text{,}\) then the whole mixture parallelogram associated to \(\vect{v}+\vect{w}\) is contained in \(W\text{.}\)
      🔗
      🔗
    3. Line Containment. If \(\vect{v}\in W\text{,}\) then the whole line \(\spn(\vect{v})\) is contained in \(W\text{.}\)
      🔗
      🔗
    🔗

    Subsets in \(\R^2\text{.}\)
    🔗
    Spans vs Subspaces. Recall that spans in \(\R^2\) are either the origin, lines through the origin, or the whole plane. Can you find a subspace in \(\R^2\) that is not a span? If yes, clearly describe this set and explain how it satisfies Insight 2.6.4. If not, explain why no such set can exist.
    🔗
    🔗
    By Proposition 2.6.2, we have shown that all spans are subspaces. What about the other way around? Is every subspace a span?
    🔗

    Definition 2.6.6. Spans (the relationship).

    If \(W\) is a subspace and \(S = \{\vect{v}_1,\ldots,\vect{v}_n\} \subset \R^m\text{,}\) then \(S\) spans \(W\) if \(\spn(S)=W\text{.}\)
    🔗
    🔗

    Remark 2.6.7. Span (the noun) vs Spans (the relationship).

    Span (the noun) and spans (the relationship) are different, but related concepts. These concepts were named this way by the mathematical community decades ago and is out of my control. For this book, if you wish, you can reference span the noun as the mixture set.
