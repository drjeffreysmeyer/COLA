    Lesson 4.5 Elimination as Matrix Multiplication

    We have seen mixture encoded as matrix multiplication. We have seen transformation encoded as matrix multiplication. Many important processes can be encoded as matrix multiplication. You will see this time after time in this text. In this lesson, you will discover how elementary row operations can be encoded as matrix multiplication (on the left).
    🔗

    Definition 4.5.1. Elementary Matrix.

    An elementary \(m\times m\) matrix is a square matrix \(E\) such that, for any \(m\times n\) matrix \(A\text{,}\) \(EA\) is obtained from \(A\) via a single row operation. In other words, if you fix a row operation \(R\text{,}\) then for all \(A\text{,}\) \(A \stackrel{R}{\sim} EA\text{.}\)
    🔗
    🔗

    Activity 4.5.2. Discovering Elementary Matrices.

    In this activity, you will explore row operations via transformations, and use this to try to classify elementary \(2\times 2\) matrices.
    🔗
    1. Part 1: From \(2\times 1\) row operation to transformation. For each of the below transformations of the plane (given to you symbolically), (1) visually sketch by hand, and clearly label, what it does to the unit square and (2) describe how it transforms the plane verbally, using complete sentences and geometric words.
      \begin{equation*} T_1:\begin{bmatrix} x\\ y\end{bmatrix} \mapsto \begin{bmatrix} y\\ x\end{bmatrix} \qquad T_2:\begin{bmatrix} x\\ y\end{bmatrix} \mapsto \begin{bmatrix} 2x\\ y\end{bmatrix} \qquad T_3:\begin{bmatrix} x\\ y\end{bmatrix} \mapsto \begin{bmatrix} x+2y\\ y\end{bmatrix}. \end{equation*}
      🔗
      🔗
    2. Part 2: From transformation to matrix. For each of the above transformations, find the matrix the encodes it. Call those matrices \(E_1\text{,}\) \(E_2\text{,}\) and \(E_3\text{,}\) respectively.
      🔗
      🔗
    3. Part 3: From matrix to row operation. Recall that if \(A= [\vect{v}_1 \mid \cdots \mid \vect{v}_n]\text{,}\) then \(EA = [E\vect{v}_1 \mid \cdots \mid E\vect{v}_n]\text{.}\) Find the elementary \(2\times 2\) matrix associated to each of the row operations:
      \begin{equation*} r_1 \leftrightarrow r_2, \qquad r_1 \mapsto 2r_1, \qquad r_1 \mapsto r_1 + 2r_2. \end{equation*}
      🔗
      🔗
    4. Part 4: Generalize. Now using your understanding of transformations and matrix multiplication of matrices, write down a complete classification of elementary matrices associated to row operations of \(2\times n\) matrices.
      🔗
      🔗
    🔗

    Proposition 4.5.3. Classification of Elementary Matrices.

    If \(E\) is a \(2\times 2\) elementary matrix, then it is of one of the following types:
    1. Permutes rows: \(\begin{bmatrix}0\amp 1\\1\amp 0\end{bmatrix}\text{,}\)
      🔗
      🔗
    2. Scales a row: \(\begin{bmatrix}a\amp 0\\0\amp 1\end{bmatrix}\) or \(\begin{bmatrix}1\amp 0\\0\amp a\end{bmatrix}\text{,}\) \(a\neq0\text{,}\) and
      🔗
      🔗
    3. Adds a multiple of a row to another: \(\begin{bmatrix}1\amp b\\0\amp 1\end{bmatrix}\) or \(\begin{bmatrix}1\amp 0\\b\amp 1\end{bmatrix}\text{.}\)
      🔗
      🔗
    Elementary \(n\times n\) matrices also fall into one of the above types with appropriate modifications.
    🔗
    🔗
    Observe that each elementary \(2\times 2\) matrix has a very simple geometric interpretation. Type 1 matrices reflect across the line \(y=x\text{,}\) Type 2 matrices stretch a single direction by a factor of \(|k|\) (and if \(k<0\) reflect in that direction as well), and Type 3 matrices are a pure shear in a given direction.
    🔗
    We may now generalize this reasoning to larger matrices. I now introduce a useful “auxiliary” object to help us reason about \(m\times m\) elementary matrices - the column of rows vector \(\vect{r}=\begin{bmatrix}r_1\\ r_2\\ \vdots \\ r_m\end{bmatrix}\text{,}\) whose entries we may think of as generic rows of an \(m\times n\) matrix. We will act upon this row vector by both elementary matrices and elementary row operations, thereby helping us connect the row operations with elementary matrices.
    🔗

    Example 4.5.4. Interpreting Elementary Matrices as Row Operations.

    If I tell you that the shear matrix
    \begin{equation*} E = \begin{bmatrix} 1\amp 0\amp 4\\0\amp 1\amp 0\\0\amp 0\amp 1\end{bmatrix} \end{equation*}
    is an elementary matrix, how can you determine the elementary matrix to which it is associated?
    🔗
    Compute (either via linear combination or pointer finger shortcut) the matrix product
    \begin{equation*} \begin{bmatrix} 1\amp 0\amp 4\\0\amp 1\amp 0\\0\amp 0\amp 1\end{bmatrix} \begin{bmatrix} r_1\\r_2\\r_3\end{bmatrix} = \begin{bmatrix} r_1+4r_3\\r_2\\r_3\end{bmatrix}. \end{equation*}
    So, multiplication by \(E\) tells us to replace row 1 with row 1 plus 4 times row 3, or in symbols, \(\RowA{1}{3}{4}\text{.}\)
    🔗
    🔗

    Activity 4.5.5. 3x3 Elementary Matrix Identification.

    Each of the below matrices are elementary \(3\times 3\) matrices. For each (1) using complete sentences, describe how the matrix transforms \(\mathbb{R}^3\text{,}\) and (2) what row operation of \(3\times n\) matrices does it encode (be precise!)?
    \begin{equation*} \begin{bmatrix} 1\amp 0\amp 0\\0\amp -2\amp 0\\0\amp 0\amp 1\end{bmatrix}, \qquad \begin{bmatrix} 1\amp 0\amp 0\\0\amp 1\amp 0\\0\amp 3\amp 1\end{bmatrix}, \qquad \begin{bmatrix} 0\amp 0\amp 1\\0\amp 1\amp 0\\1\amp 0\amp 0\end{bmatrix}. \end{equation*}
    🔗
    🔗
    To determine the matrix associated to a row operation, there are several strategies. One such strategy is to write down the “new” column of rows, expand it as a linear combination of the original rows, and use matrix multiplication as linear combination to deduce the matrix.
    🔗

    Example 4.5.6. Encoding a Row Operation as an Elementary Matrix.

    What \(3\times 3\) elementary matrix encodes the row operation replace row 3 with row 3 plus 2 times row 1, or in symbols, \(\RowA{3}{1}{2}\text{?}\)
    🔗
    We want an unknown \(3\times 3\) matrix \(E\) satisfying
    \begin{equation*} E \begin{bmatrix} r_1\\r_2\\r_3\end{bmatrix} = \begin{bmatrix} r_1\\r_2\\r_3+2r_1\end{bmatrix} = r_1\begin{bmatrix} 1\\0\\2\end{bmatrix} + r_2\begin{bmatrix} 0\\1\\0\end{bmatrix} + r_3\begin{bmatrix} 0\\0\\1\end{bmatrix}. \end{equation*}
    Via definition of matrix multiplication as linear combination,
    \begin{equation*} E = \begin{bmatrix} 1\amp 0\amp 0\\0\amp 1\amp 0\\2\amp 0\amp 1\end{bmatrix}. \end{equation*}
    🔗
    🔗
    Now that we can encode a single row operation as multiplication by a single elementary matrix, it follows that a sequence of row operations can be encoded by a product of elementary matrices. In particular, Gaussian elimination can be expressed via a product of elementary matrices!
    🔗
    Let us now revisit our example:
    \begin{equation*} \left[\begin{array}{cc|c} 1 \amp -1 \amp 1 \\ 1 \amp 1 \amp 5 \end{array}\right] \rowA{2}{1}{-1} \left[\begin{array}{cc|c} 1 \amp -1 \amp 1 \\ 0 \amp 2 \amp 4 \end{array}\right] \rowS{2}{\frac{1}{2}} \left[\begin{array}{cc|c} 1 \amp -1 \amp 1 \\ 0 \amp 1 \amp 2 \end{array}\right] \rowA{1}{2}{1} \left[\begin{array}{cc|c} 1 \amp 0 \amp 3 \\ 0 \amp 1 \amp 2 \end{array}\right]. \end{equation*}
    In terms of elementary matrices, this can be re-written as:
    \begin{equation} \begin{bmatrix} 1\amp 1\\0\amp 1\end{bmatrix} \begin{bmatrix} 1\amp 0\\0\amp \frac{1}{2}\end{bmatrix} \begin{bmatrix} 1\amp 0\\-1\amp 1\end{bmatrix} \left[\begin{array}{cc|c} 1\amp -1\amp 1\\1\amp 1\amp 5\end{array}\right] = \left[\begin{array}{cc|c} 1\amp 0\amp 3\\0\amp 1\amp 2\end{array}\right].\tag{4.5.1} \end{equation}
    Observe now how the system equation, the augmented matrix row reduction, and (4.5.1) encode the same information.
    🔗

    Activity 4.5.7. Elimination as Matrix Multiplication.

    Consider the matrix equation
    \begin{equation*} \begin{bmatrix} 2\amp -2\\1\amp 1\end{bmatrix}\begin{bmatrix} x\\y\end{bmatrix}=\begin{bmatrix} -4\\8\end{bmatrix}. \end{equation*}
    🔗
    1. Row operations. Re-write this matrix equation as an augmented matrix and solve it via Gaussian elimination.
      🔗
      🔗
    2. Elementary matrices. Re-interpret your sequence of row operations as a single product of elementary matrices, as in (4.5.1).
      🔗
      🔗
    🔗
    It will be useful in many situations to record sequences of row operations as multiplication by matrices.
    🔗
    To conclude this lesson, I want to reiterate that matrix multiplication is a concept we already understand and will continue to develop more insights and tools throughout this course. Therefore, it is productive to be able to identify processes we encounter as coming from matrix multiplication, as we may then use the tools of matrix multiplication to analyze these processes. In this lesson, we encoded the process of row operation as matrix multiplication on the left by elementary matrices. We will revisit in future lessons both (1) elementary matrices and (2) the mental act of encoding new processes as matrix multiplication.
