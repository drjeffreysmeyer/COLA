Definition 2.4.12. Solution Vectors.

If \(S=\{\vect{v}_1, \ldots, \vect{v}_n\}\subset \R^m\text{,}\) \(\vect{b}\in \R^m\text{,}\) and \(x_1,\ldots, x_n\in \R\) are such that \(x_1\vect{v}_1+\cdots+x_n\vect{v}_n=\vect{b}\text{,}\) then the associated servings vector \(\begin{bmatrix}x_1\\ \vdots\\ x_n\end{bmatrix}\) is a solution vector for making \(\vect{b}\) with \(S\text{.}\)
