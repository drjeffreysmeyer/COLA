Definition 4.3.3. Row Operations.

The three fundamental row operations are:
🔗
  1. Permute rows \(i\) and \(j\text{.}\) We denote this by \(r_i \leftrightarrow r_j\text{.}\)
    🔗
    🔗
  2. Scale row \(i\) by nonzero scalar \(k\text{.}\) We denote this by \(r_i \mapsto kr_i\text{.}\)
    🔗
    🔗
  3. Add a scalar multiple of row \(j\) to row \(i\text{.}\) We denote this by \(r_i \mapsto r_i+kr_j\text{.}\)
    🔗
    🔗
We read these as “Row \(i\) is replaced by...” or “Row \(i\) becomes...”.
