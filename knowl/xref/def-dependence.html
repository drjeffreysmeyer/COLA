Definition 2.5.1. Linear (In)Dependence.

If \(S\subset \R^m\) is a (nonempty) finite subset of vectors such that one of its vectors can be written as a linear combination of its other vectors, then the subset \(S\) is linearly dependent. In symbols, \(S=\{\vect{v}_1,\vect{v}_2, \ldots, \vect{v}_n\}\) is dependent if there exists an \(i\in \{1, \ldots , n\}\) and, for each \(j\in \{1,\ldots,n\} - \{i\}\text{,}\) a number \(x_j\in \R\text{,}\) such that
🔗
\begin{equation} \vect{v}_i=x_1\vect{v}_1+\cdots +x_{i-1}\vect{v}_{i-1}+x_{i+1}\vect{v}_{i+1}+\cdots +x_n\vect{v}_n.\tag{2.5.1} \end{equation}
This is a dependency equation for \(S\text{.}\) If no such equation exist, then \(S\) is linearly independent.
