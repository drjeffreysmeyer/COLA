Definition 3.1.14. Matrix Multiplication (Matrix with Matrix).

If \(A\) is an \(m\times n\) matrix and \(B=[\vect{w}_1| \cdots | \vect{w}_p]\) is an \(n\times p\) matrix (i.e. \(\vect{w}_1,\ldots, \vect{w}_p\in\R^n\)), then the matrix multiplication of matrices \(A\) and \(B\) is
🔗
\begin{equation} AB = [\ A\vect{w}_1 \ | \cdots \ | \ A \vect{w}_p\ ].\tag{3.1.1} \end{equation}
The resulting \(m\times p\) matrix is their product.
