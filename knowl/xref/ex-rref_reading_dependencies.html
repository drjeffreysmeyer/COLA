Example 5.1.1. Extracting Dependency Equations from Null Space.

Suppose \(S=\{\vect{v}_1, \ldots, \vect{v}_5\}\subset \mathbb{R}^3\) and
\begin{equation*} \rref\left([A_S \mid \vect{0}]\right) = \left[\begin{array}{ccccc|c} 1 \amp 5 \amp 0 \amp 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 1 \amp 0 \amp 3 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \amp 4 \amp 0 \end{array}\right]. \end{equation*}
What can we say about the dependencies of \(S\text{?}\) Using the analysis of Lesson 4.4,
\begin{equation*} \Null(A_S) = \left\{ x_2\begin{bmatrix}-5\\1\\0\\0\\0\end{bmatrix} + x_5\begin{bmatrix}-2\\0\\-3\\-4\\1\end{bmatrix} \ \bigg| \ x_2,x_5\in \mathbb{R} \right\}. \end{equation*}
Observe that each of the velocity vectors of the parametric vector form of \(\Null(A_S)\) is a servings vector to make zero, and hence is algebraically equivalent to a dependency equation:
\begin{align*} \begin{bmatrix}-5\\1\\0\\0\\0\end{bmatrix} \in \Null(A_S) \amp\implies -5\vect{v}_1 + \vect{v}_2 = \vect{0} \amp\implies \vect{v}_2 = 5\vect{v}_1. \\\\ \begin{bmatrix}-2\\0\\-3\\-4\\1\end{bmatrix} \in \Null(A_S) \amp\implies -2\vect{v}_1 - 3\vect{v}_3 -4\vect{v}_4 + \vect{v}_5 = \vect{0} \amp\implies \vect{v}_5 = 2\vect{v}_1 + 3\vect{v}_3 + 4\vect{v}_4. \end{align*}
All other dependencies are combinations of these, so we conclude \(\{\vect{v}_1, \vect{v}_3, \vect{v}_4\}\) is independent. Furthermore, since \(\vect{v}_2,\vect{v}_5\in \spn(\vect{v}_1, \vect{v}_3, \vect{v}_4)\text{,}\) we conclude \(\spn(\vect{v}_1, \vect{v}_3, \vect{v}_4)= \spn(S)\text{.}\)
