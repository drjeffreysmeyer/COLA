Example 2.5.10. Visualizing Null Vectors.

Here I investigate null vectors for \(S= \{\vect{v}_1,\vect{v}_2,\vect{v}_3\} = \left\{ \begin{bmatrix}1\\-1\end{bmatrix}, \begin{bmatrix}2\\2\end{bmatrix}, \begin{bmatrix}-3\\1\end{bmatrix}\right\}.\) I know \(\begin{bmatrix}0\\0\\0\end{bmatrix}\) is a null vector for \(S\text{.}\) (Why?) For this particular \(S\text{,}\) I can find a nonzero null vector. Using the tip-to-tail visualization, I will have found a null vector for the three vectors in \(S\) precisely when the scaled vectors, placed tip-to-tail, form a closed triangle. (Why?) In this instance, I can close off the triangle using 2 units of \(\vect{v}_1\text{,}\) \(\frac{1}{2}\) a unit of \(\vect{v}_2\text{,}\) and \(1\) unit of \(\vect{v}_3\text{.}\) So I have found that \(\begin{bmatrix}2\\ \frac{1}{2}\\ 1\end{bmatrix}\) is a null vector for \(S\text{.}\)
