Definition 2.1.22. Servings Vector.

If \(S=\{\vect{v}_1,\ldots, \vect{v}_n\} \subset\R^m\) are distinct vectors with a fixed order and \(x_1,\ldots, x_n\in\R\) are scalars, then the linear combination
\begin{equation*} x_1\vect{v}_1+\cdots + x_n\vect{v}_n \end{equation*}
has servings vector \(\vect{x}=\begin{bmatrix}x_1\\ \vdots \\ x_n\end{bmatrix}\text{.}\)
