Definition 9.1.1. Invariant Lines.

If \(T:\R^n\to \R^n\) is a matrix transformation with associated matrix \(A\text{,}\) then a line \(L\) through the origin (a.k.a. a 1-dimensional subspace) is \(T\)-invariant (or \(A\)-invariant) if it is sent into itself under the transformation. Symbolically, \(T(L)\subset L\text{.}\) When \(T\) is clear from context, we will usually drop reference to \(A\) or \(T\) and just say the line is invariant.
