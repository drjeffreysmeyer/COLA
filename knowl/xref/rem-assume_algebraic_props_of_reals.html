Definition 2.2.6. Algebraic Properties of Real Numbers.

Real numbers satisfy the following algebraic properties.
🔗
  1. Addition and multiplication are associative: If \(a,b,c \in \R\text{,}\) then \((a+b)+c=a+(b+c)\) and \((ab)c=a(bc)\text{.}\)
    🔗
    🔗
  2. Additive and multiplicative identities: The element \(0\in \R\) satisfies the property: if \(a\in \R\text{,}\) then \(0+a=a\text{.}\) The element \(1\in \R\) satisfies the property: if \(a\in \R\text{,}\) then \(1a=a\text{.}\)
    🔗
    🔗
  3. There exist additive and multiplicative inverses: If \(a\in \R\text{,}\) then there exists an element \(-a\in \R\) such that \(a+(-a)=0\text{.}\) If \(a\in \R-\{0\}\text{,}\) then there exists an element \(a^{-1}\in \R-\{0\}\) such that \(aa^{-1}=1\text{.}\)
    🔗
    🔗
  4. Addition and multiplication are commutative: If \(a,b \in \R\text{,}\) then \(a+b=b+a\) and \(ab=ba\text{.}\)
    🔗
    🔗
  5. Addition and multiplication are tied together with distributivity: If \(a,b,c \in \R\text{,}\) then \(a(b+c)=ab+ac\text{.}\)
    🔗
    🔗
