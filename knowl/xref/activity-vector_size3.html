Activity 10.1.3. Size in \(\R^3\).

Investigate the size of each vector in \(S= \{\vect{v}_1,\vect{v}_2,\vect{v}_3\} = \left\{ \left[\begin{array}{r}6\\0\\0\end{array}\right],\left[\begin{array}{r}1\\5\\5\end{array}\right], \left[\begin{array}{r}4\\4\\4\end{array}\right]\right\}.\) Make an argument why each vector could be considered to have the largest size. (Note: each of them has a reasonable argument - think it through!)
