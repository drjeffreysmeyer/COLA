Proposition 2.3.3. Parametric Vector Form of Lines in \(\R^2\).

If \(\ell\) is a line in \(\R^2\text{,}\) then there exists vectors \(\vect{v},\vect{p}\in \R^2\) such that \(\ell = \{\vect{p}+t\vect{v} \ \big| \ t\in \R\}\text{.}\)
🔗
🔗

Proof.

To begin, suppose \(\ell\) is not vertical and has slope-intercept equation \(y=mx+b\text{.}\) If \((x,y)\) are the coordinates of a point on \(\ell\text{,}\) then we may substitute for \(y\text{:}\)
\begin{equation*} \begin{bmatrix}x\\y\end{bmatrix} = \begin{bmatrix}x\\mx+b\end{bmatrix} = \begin{bmatrix}0\\b\end{bmatrix} + x\begin{bmatrix}1 \\m\end{bmatrix}. \end{equation*}
Name \(\vect{p}=\begin{bmatrix}0\\b\end{bmatrix}\) and \(\vect{v}=\begin{bmatrix}1 \\m\end{bmatrix}\text{.}\) Then \(\begin{bmatrix}x\\y\end{bmatrix} = \vect{p}+x\vect{v}\text{.}\) Since this is true for all \(x\in \R\text{,}\) it follows that \(\ell = \{\vect{p}+t\vect{v} \ \big| \ t\in \R\}\text{.}\) The case when \(\ell\) is vertical is left as an exercise.
