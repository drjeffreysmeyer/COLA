Definition 3.3.5. Transformed Sets.

If \(T:\mathbb{R}^n\to\mathbb{R}^m\) is a matrix transformation and \(X\subset \mathbb{R}^n\) is a set of points, then the transformed set is the set of points in \(\mathbb{R}^m\) obtained by recording where \(T\) sends each point of \(X\text{.}\)
🔗
In symbols \(T(X) = \{ T(\vect{x}) \mid \vect{x}\in X\}\) and we say \(T\) sends \(X\) to \(T(X)\text{.}\) We may also say \(T(X)\) is the image of \(X\) under \(T\text{.}\)
