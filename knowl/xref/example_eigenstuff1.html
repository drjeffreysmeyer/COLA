Example 9.2.1.

Let \(A=\left[ \begin{array}{rr}2.5 \amp -0.5 \\ -0.5 \amp 2.5 \end{array}\right]\text{.}\) Using the Invariant Line tool, we can quickly find its invariant lines and their associated scaling factors. Let’s now try this algebraically.
🔗
Step 1. Find the polynomial
🔗
\begin{equation*} p_A(\lambda)=\det\left[ \begin{array}{cc}2.5-\lambda \amp -0.5 \\ -0.5 \amp 2.5-\lambda \end{array}\right]= \lambda^2-5\lambda+6 = (\lambda-2)(\lambda-3). \end{equation*}
Step 2. The possible scaling factors are the roots of \(p_A(\lambda)\text{,}\) namely \(\lambda=2,3\text{.}\)
🔗
Step 3. For each scaling factor, we find the associated invariant line.
🔗
\begin{equation*} \lambda_1=2: \hspace{2pc} \left[ \begin{array}{cc|c}2.5-2 \amp -0.5 \amp 0 \\ -0.5 \amp 2.5-2 \amp 0 \end{array}\right] = \left[ \begin{array}{rr|r}0.5 \amp -0.5 \amp 0 \\ -0.5 \amp 0.5 \amp 0 \end{array}\right]\sim \left[ \begin{array}{rr|r}1 \amp -1 \amp 0 \\ 0 \amp 0 \amp 0 \end{array}\right]. \end{equation*}
The invariant line with scaling factor 2 is \(E_2:=\Null(A-2I) = \left\{t\left[ \begin{array}{r}1 \\ 1 \end{array}\right] \ \big| \ t\in \R\right\}.\)
🔗
\begin{equation*} \lambda_2=3: \hspace{2pc} \left[ \begin{array}{cc|c}2.5-3 \amp -0.5 \amp 0 \\ -0.5 \amp 2.5-3 \amp 0 \end{array}\right] = \left[ \begin{array}{rr|r}-0.5 \amp -0.5 \amp 0 \\ -0.5 \amp -0.5 \amp 0 \end{array}\right]\sim \left[ \begin{array}{rr|r}1 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \end{array}\right]. \end{equation*}
The invariant line with scaling factor 3 is \(E_3:=\Null(A-3I) = \left\{t\left[ \begin{array}{r}-1 \\ 1 \end{array}\right] \ \big| \ t\in \R\right\}\text{.}\)
🔗
Observe \(\vect{v}_1=\left[ \begin{array}{r}1 \\ 1 \end{array}\right]\) is a nice choice for a nonzero vector on \(E_2\) and \(\vect{v}_2=\left[ \begin{array}{r}-1 \\ 1 \end{array}\right]\) is a nice choice for a nonzero vector on \(E_3\text{.}\) The basis \(\mathcal{B}=\{\vect{v}_1,\vect{v}_2\}\) is a good basis for understanding \(A\text{,}\) namely, \(A\) stretched the \(\vect{v}_1\)-direction by a factor of \(2\) and stretches the \(\vect{v}_2\)-direction by a factor of 3. This gives us a nice similar matrix decomposition where \(A\) is similar to a diagonal matrix: \(A=\left[ \begin{array}{rr}1 \amp -1 \\ 1 \amp 1 \end{array}\right]\left[ \begin{array}{rr}2 \amp 0 \\ 0 \amp 3 \end{array}\right]\left[ \begin{array}{rr}1 \amp -1 \\ 1 \amp 1 \end{array}\right]^{-1}\) (cf. Example Example 7.1.6).
