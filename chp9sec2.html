    Lesson 8.2 Algebraic Properties of the Determinant

    We conceptualize the determinant as originating as a geometric object, measuring geometric properties of transformations. However, from this conceptualization emerges numerous valuable algebraic properties. In this lesson we will develop some of these algebraic properties.
    🔗
    From observations in the previous sections on \(\operatorname{vsf}\) and \(\sgn\text{,}\) we get the following two propositions.
    🔗

    Proposition 8.2.1. Elementary Matrix Rules.

    If \(E\) is an elementary matrix, then
    🔗
    \begin{equation*} \det(E)= \begin{cases} -1 \amp \text{if } E \text{ is type 1,}\\ k \amp \text{if } E \text{ is type 2 with scaling factor } k\text{, and}\\ 1 \amp \text{if } E \text{ is type 3.} \end{cases} \end{equation*}
    🔗

    Remark 8.2.2.

    Observe that the determinant of an elementary matrix is never zero.
    🔗
    🔗
    Since both \(\operatorname{vsf}\) and \(\sgn\) satisfy the product formula, so does \(\det\text{!}\)
    🔗

    Proposition 8.2.3. Product Formula.

    If \(A\) and \(B\) are \(n\times n\) matrices, then
    🔗
    \begin{equation*} \det (AB) = \det (A)\det(B). \end{equation*}
    🔗
    Taking Proposition 8.2.1 and Proposition 8.2.3 as our core determinant properties, we may both rigorously deduce all other algebraic properties of the determinant and compute determinants.

    🔗
    More generally, we have the following strategy for computing determinants using elementary matrix decompositions.
    🔗

    Proposition 8.2.5. Reading \(\det\) from an EMD.

    If \(A\) is an \(n\times n\) matrix with elementary matrix decomposition \(A=E_1\cdots E_r \operatorname{rref}(A)\text{,}\) with \(t_1\) many type 1 elementary matrices, and \(t_2\) many type 2 elementary matrices with scaling factors \(k_1,\ldots, k_{t_2}\text{,}\) then
    🔗
    \begin{equation*} \det(A)=\begin{cases}0\amp \text{if } \operatorname{rref}(A)\ne I,\\ (-1)^{t_1}(k_1\cdots k_{t_2})\amp \text{if } \operatorname{rref}(A)=I.\end{cases} \end{equation*}
    🔗

    Proof.

    If \(\operatorname{rref}(A)\ne I\text{,}\) then \(\operatorname{rref}(A)\text{,}\) and hence \(A\text{,}\) is a projection, so \(A\) has volume scaling factor 0. If \(\operatorname{rref}(A)=I\text{,}\) then \(A\) is a product of elementary matrices. The computation follows from putting together Proposition 8.2.1 and Proposition 8.2.3.
    🔗
    🔗
    Proposition 8.2.5 is useful for computing the determinant of any matrix. In the next section, I will discuss other strategies for computation.
    🔗

    Proposition 8.2.6. Determinant of Triangular Matrices.

    If \(T\) is a lower (or upper) triangular matrix with diagonal entries \(d_1,d_2, \ldots d_n\text{,}\) then \(\det(T)=d_1d_2\cdots d_n\text{.}\)
    🔗
    🔗

    Proof.

    The details of this proof I leave as a homework assignment. I will give a few hints.
    🔗
    First, show that if none of the \(d_i\)’s are \(0\text{,}\) then there exists a sequence of type 3 row operations reducing \(T\) to the diagonal matrix \(T_0\) with diagonal entries \(d_1,d_2, \ldots d_n\text{.}\)
    🔗
    Second, if one of the \(d_i\)’s is \(0\text{,}\) then \(\det(T)=0\text{.}\) Among other results, you may find Proposition 8.2.1, Proposition 8.2.3, as well as the big ideas of Lesson 7.3, useful.
    🔗
    🔗
    Conceptually, the only class of matrix transformation not invertible are projections, which happen to smash volumes to zero. It turns out that the determinant is a useful criteria to distinguish projections from the invertible transformations.
    🔗

    Proposition 8.2.7. The Determinant and Invertibility.

    If \(A\) is an \(n\times n\) matrix, then the following two statements are equivalent:
    🔗
    \begin{equation*} \text{A is invertible} \iff \det(A)\ne 0. \end{equation*}
    🔗

    Proof.

    To show equivalence, I need to show each implies the other.
    🔗
    To begin, write \(A=E_1\cdots E_r \operatorname{rref}(A)\) where \(E_i\) are elementary matrices. Since elementary matrices have nonzero determinant (Proposition 8.2.1), the product formula (Proposition 8.2.3) and the fact that the product of nonzero real numbers is nonzero implies that \(c = \det(E_1\cdots E_r)\) is a nonzero number. Hence the product formula implies \(\det(A) = c\det(\operatorname{rref}(A))\text{.}\)
    🔗
    If \(A\) is invertible, then \(\operatorname{rref}(A)=I\) (Algorithm Proposition 6.2.1) and we deduce \(\det(A)=c\ne0\text{.}\)
    🔗
    If \(A\) is not invertible, then \(\operatorname{rref}(A)\ne I\) is a projection, hence \(\det(A) = c(0)=0\text{.}\) Since a statement is logically equivalent to its contrapositive, we deduce that if \(\det(A) \ne 0\text{,}\) then \(A\) is invertible.
    🔗
    🔗
    Proposition 8.2.7 is an important computational check that is added to The List.
    🔗
    We now discuss two useful algebraic properties of the determinant. They both have clear geometric interpretations and can be rigorously proven from above known propositions. Make sure you understand both!
    🔗

    Activity 8.2.8.

    Give a geometric explanation as to why \(\begin{bmatrix}2\amp 0\\0\amp 3 \end{bmatrix}\) and \(\begin{bmatrix}\frac{1}{2}\amp 0\\0\amp \frac{1}{3}\end{bmatrix}\) have reciprocal determinants.
    🔗
    🔗
    If a matrix transformation \(T\) is invertible, then whatever \(T\) does to volumes and sign, its inverse \(T^{-1}\) should undo it.
    🔗

    Proposition 8.2.9. Determinant of the Inverse.

    If \(A\) is invertible, then \(\det(A^{-1}) = \frac{1}{\det(A)}\text{.}\)
    🔗
    🔗

    Proof.

    Since \(A\) is invertible, it has an inverse \(A^{-1}\) which satisfies the equation \(AA^{-1}=I\) (Definition Definition 6.1.3). Using the Product Formula (Proposition 8.2.3),
    🔗
    \begin{equation*} \det(A)\det(A^{-1}) = \det(AA^{-1})=\det(I)=1. \end{equation*}
    Then solve for \(\det(A^{-1})\text{.}\)
    🔗
    🔗

    Proposition 8.2.10. Determinant of the Transpose.

    If \(A\) is square, then \(\det(A^{T}) = \det(A)\text{.}\)
    🔗
    🔗

    Proof.

    I will prove this assuming \(A\) has an \(LU\)-decomposition (which will generically be the case). I will leave the case in which it does not to you. Write \(A= LU\text{.}\) Using the Sock and Shoes property of transpose (Proposition ), \(A^T=(LU)^T=U^TL^T\text{.}\) Observe that the transpose of a lower (resp. upper) triangular matrix is an upper (resp. lower) triangular matrix. Furthermore, the diagonals of a triangular matrix and its transpose are the same. Using Proposition 8.2.6, \(\det(U)=\det(U^T)\) and \(\det(L)=\det(L^T)\text{.}\) Using the Product Formula Proposition 8.2.3 and putting this all together:
    🔗
    \begin{equation*} \det(A^T)=\det(U^TL^T)=\det(U^T)\det(L^T)= \det(U)\det(L)=\det(L)\det(U)=\det(LU)=\det(A). \end{equation*}
    🔗

    Activity 8.2.11.

    Revisit Example Example 7.1.6 and give a geometric explanation as to why \(\begin{bmatrix}2.5\amp -0.5\\-0.5\amp 2.5\end{bmatrix}\) and \(\begin{bmatrix}2\amp 0\\0\amp 3\end{bmatrix}\) have the same determinant.
    🔗
    🔗
    Fixing a matrix \(A\text{,}\) it does not matter which region of \(\mathbb{R}^n\) you are looking at, be it the unit square, a \(\mathcal{B}\)-unit square, or something else, the volume scaling factor, sign, and hence determinant are all the same.
    🔗

    Proposition 8.2.12. Determinants of Similar Matrices.

    If \(\mathcal{B}\) is a basis and \(A=P_{\mathcal{B}}BP_{\mathcal{B}}^{-1}\text{,}\) then \(\det(A) = \det (B)\text{.}\)
    🔗
    🔗

    Proof.

    Using the Product Formula Proposition 8.2.3 and Proposition Proposition 8.2.9:
    🔗
    \begin{equation*} \det(A) = \det(P_{\mathcal{B}}BP_{\mathcal{B}}^{-1}) = \rst{\det(P_{\mathcal{B}})}\det(B)\rst{\det(P_{\mathcal{B}}^{-1})} = \det(B). \end{equation*}
