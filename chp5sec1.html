    Lesson 5.1 Dependency Analysis

    Recall that \(S\subset \mathbb{R}^m\) is linearly dependent if one of its vectors is a linear combination of the others (Definition 2.5.1). In symbols, \(S=\{\vect{v}_1,\vect{v}_2, \ldots, \vect{v}_n\}\) is dependent if there exists an \(i\in \{1, \ldots , n\}\) and, for each \(j\in \{1,\ldots,n\}-\{i\}\text{,}\) a number \(x_j\in \mathbb{R}\text{,}\) such that
    \begin{equation*} \vect{v}_i=x_1\vect{v}_1+x_2\vect{v}_2+\cdots +x_{i-1}\vect{v}_{i-1}+x_{i+1}\vect{v}_{i+1}+\cdots +x_n\vect{v}_n. \end{equation*}
    This is a dependency equation, or more succinctly, a dependency for \(S\text{.}\) In this lesson, we revisit the concepts of dependency and use the tools of \(\rref\) to analyze the dependency equations of \(S\text{.}\)
    🔗
    A dependency equation is algebraically equivalent to making zero in a nontrivial way (Proposition 2.5.9). In the compact notation of matrix multiplication, this is then expressed as a solution vector to the matrix equation \(A_S\vect{x}=\vect{0}\) (i.e., a null vector). Computing \(\rref([A_S \mid \vect{0}])\text{,}\) we can now find the parametric vector form of \(\Null(A_S)\text{,}\) each of whose vectors can be understood as encoding a dependency equation.
    🔗

    Example 5.1.1. Extracting Dependency Equations from Null Space.

    Suppose \(S=\{\vect{v}_1, \ldots, \vect{v}_5\}\subset \mathbb{R}^3\) and
    \begin{equation*} \rref\left([A_S \mid \vect{0}]\right) = \left[\begin{array}{ccccc|c} 1 \amp 5 \amp 0 \amp 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 1 \amp 0 \amp 3 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \amp 4 \amp 0 \end{array}\right]. \end{equation*}
    What can we say about the dependencies of \(S\text{?}\) Using the analysis of Lesson 4.4,
    \begin{equation*} \Null(A_S) = \left\{ x_2\begin{bmatrix}-5\\1\\0\\0\\0\end{bmatrix} + x_5\begin{bmatrix}-2\\0\\-3\\-4\\1\end{bmatrix} \ \bigg| \ x_2,x_5\in \mathbb{R} \right\}. \end{equation*}
    Observe that each of the velocity vectors of the parametric vector form of \(\Null(A_S)\) is a servings vector to make zero, and hence is algebraically equivalent to a dependency equation:
    \begin{align*} \begin{bmatrix}-5\\1\\0\\0\\0\end{bmatrix} \in \Null(A_S) \amp\implies -5\vect{v}_1 + \vect{v}_2 = \vect{0} \amp\implies \vect{v}_2 = 5\vect{v}_1. \\\\ \begin{bmatrix}-2\\0\\-3\\-4\\1\end{bmatrix} \in \Null(A_S) \amp\implies -2\vect{v}_1 - 3\vect{v}_3 -4\vect{v}_4 + \vect{v}_5 = \vect{0} \amp\implies \vect{v}_5 = 2\vect{v}_1 + 3\vect{v}_3 + 4\vect{v}_4. \end{align*}
    All other dependencies are combinations of these, so we conclude \(\{\vect{v}_1, \vect{v}_3, \vect{v}_4\}\) is independent. Furthermore, since \(\vect{v}_2,\vect{v}_5\in \spn(\vect{v}_1, \vect{v}_3, \vect{v}_4)\text{,}\) we conclude \(\spn(\vect{v}_1, \vect{v}_3, \vect{v}_4)= \spn(S)\text{.}\)
    🔗
    🔗
    Observe how in Example 5.1.1, the dependency equations can be seen in columns 2 and 5. This is not a coincidence and we will now explore a distinct but equivalent interpretation of \(\rref([A_S \mid \vect{0}])\text{.}\)
    🔗
    For any \(m\times n\) matrix \(B\) and list-length \(m\) vectors \(\vect{a}\) and \(\vect{b}\text{,}\) if you put \([B \mid \vect{a} \mid \vect{b}]\) in rref, then you will have put \([B \mid \vect{a}]\) in rref. In symbols, if \(\rref\left([B \mid \vect{a} \mid \vect{b}]\right) = [C \mid \vect{c} \mid \vect{d}]\text{,}\) then \(\rref\left([B \mid \vect{a}]\right) = [C \mid \vect{c}]\text{.}\) A useful mnemonic for this is “you can slide the equals bar.”
    🔗

    Example 5.1.2. Sliding the Equals Bar.

    Returning to Example 5.1.1, we have each of the following:
    \begin{equation*} \rref\left([A_S \mid \vect{0}]\right) = \left[\begin{array}{ccccc|c} 1 \amp 5 \amp 0 \amp 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 1 \amp 0 \amp 3 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \amp 4 \amp 0 \end{array}\right] \end{equation*}
    \begin{equation*} \begin{cases} \rref\left([\vect{v}_1 \mid \vect{v}_2]\right) = \left[\begin{array}{c|c} 1 \amp 5 \\ 0 \amp 0 \\ 0 \amp 0 \end{array}\right] \implies \vect{v}_2=5\vect{v}_1 \\ \rref\left([\vect{v}_1 \mid \vect{v}_3]\right) = \left[\begin{array}{c|c} 1 \amp 0 \\ 0 \amp 1 \\ 0 \amp 0 \end{array}\right] \implies \vect{v}_3\notin \spn(\vect{v}_1) \implies \{\vect{v}_1,\vect{v}_3\} \text{ is independent} \\ \rref\left([\vect{v}_1 \mid \vect{v}_3 \mid \vect{v}_4]\right) = \left[\begin{array}{cc|c} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{array}\right] \implies \vect{v}_4\notin \spn(\vect{v}_1,\vect{v}_3) \implies \{\vect{v}_1,\vect{v}_3,\vect{v}_4\} \text{ is independent} \\ \rref\left([\vect{v}_1 \mid \vect{v}_3 \mid \vect{v}_4 \mid \vect{v}_5]\right) = \left[\begin{array}{ccc|c} 1 \amp 0 \amp 0 \amp 2 \\ 0 \amp 1 \amp 0 \amp 3 \\ 0 \amp 0 \amp 1 \amp 4 \end{array}\right] \implies \vect{v}_5=2\vect{v}_1+3\vect{v}_3+4\vect{v}_4. \end{cases} \end{equation*}
    Consistent with Example 5.1.1, we conclude:
    🔗
    1. \(S_0 = \{\vect{v}_1, \vect{v}_3, \vect{v}_4\}\) is independent,
      🔗
      🔗
    2. \(\vect{v}_2=5\vect{v}_1\) and \(\vect{v}_5=2\vect{v}_1+3\vect{v}_3+4\vect{v}_4\) are dependency equations, and
      🔗
      🔗
    3. \(\spn(\vect{v}_1, \vect{v}_3, \vect{v}_4)= \spn(S)\text{.}\)
      🔗
      🔗
    🔗
    A quick remark about sliding the equals bar. In Example 5.1.2, we separately rewrote \(\rref([\vect{v}_1 \mid \vect{v}_2])\text{,}\) \(\rref([\vect{v}_1 \mid \vect{v}_2 \mid \vect{v}_3])\text{,}\) and so on. In practice, we do not rewrite these. Rather we just look at \(\rref(A_S)\) and mentally focus attention on the relevant columns.
    🔗
    We now generalize these examples to an arbitrary \(S\subset \mathbb{R}^m-\{\vect{0}\}\text{.}\) From \(\rref(A_S)\) we are going to build a subset of vectors \(S_0\subset S\) which is independent and satisfies \(\spn(S_0)=\spn(S)\text{,}\) and furthermore find explicit dependency equations for each \(\vect{v}\in S-S_0\text{.}\)
    🔗
    Start with \(S_0\) containing \(\vect{v}_1\) and analyze \(\rref(A_S)\) to determine what other columns to include. Suppose we have computed (or are given) \(\rref([\vect{v}_1 \mid \cdots \mid \vect{v}_n])\text{.}\) We may now “slide the equals bar” and look at each \(\rref([\vect{v}_1 \mid \vect{v}_2])\text{,}\) \(\rref([\vect{v}_1 \mid \vect{v}_2 \mid \vect{v}_3])\text{,}\) and so on. At each step, we interpret the rref. Say we are looking at \(\rref([\vect{v}_1 \mid \cdots \mid \vect{v}_i])\) for some \(i\in\{2,\ldots, n\}\text{.}\) We will encounter one of two possible cases:
    🔗
    Case 1. If \(A_S\) has a pivot position in its \(i^{\text{th}}\) column (i.e., its \(i^{\text{th}}\) column is a pivot column), then in \(\rref([\vect{v}_1 \mid \cdots \mid \vect{v}_i])\) we will see a zero-one row, and hence there is no way to make that vector from the previous independent vectors. We include \(\vect{v}_i\) in \(S_0\text{.}\)
    🔗
    Case 2. If the \(i^{\text{th}}\) column of \(A_S\) is not a pivot column, then the \(i^{\text{th}}\) column of \(\rref(A_S)\) is the servings vector to make \(\vect{v}_i\) from the previous independent vectors in \(S_0\text{.}\) This gives us a dependency equation for \(\vect{v}_i\text{.}\)
    🔗

    Insight 5.1.3. Dependency Analysis.

    If \(S=\{\vect{v}_1,\ldots, \vect{v}_n\}\subset \mathbb{R}^m\) are nonzero vectors and \(A_S=[\vect{v}_1 \mid \cdots \mid \vect{v}_n]\text{,}\) how can we read dependencies from \(\rref(A_S)\text{?}\)
    🔗
    1. Look at the columns of \(\rref(A_S)\) from left to right.
      🔗
      🔗
    2. If \(S_0\subset S\) is the set of pivot columns of \(A_S\text{,}\) then \(S_0\) is independent and \(\spn(S_0)=\spn(S)\text{.}\)
      🔗
      🔗
    3. A column in \(\rref(A_S)\) with a free variable is a servings vector for how to build that column from the previous pivot columns.
      🔗
      🔗
    🔗
    Keep in mind that “sliding the equals bar” and Insight 5.1.3 are essentially just a shortcut to interpreting the standard velocity vectors in the parametric vector form of \(\Null(A_S)\) as dependency equations.
    🔗

    Activity 5.1.4. Dependency Analysis Activity.

    You start with an ordered list of five vectors, \(S=\{\vect{v}_1, \ldots \vect{v}_5\}\subset \mathbb{R}^m\text{.}\) You want to determine the dependencies, throw out redundancies, and get an independent collection with the same span, so you compute \(\rref(A_S)\text{.}\) For each rref matrix below, using Insight 5.1.3 for guidance, explain which vectors you keep and the servings to make each vector you throw out.
    \begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 5 \amp 1 \amp 2 \\ 0 \amp 1 \amp 6 \amp 3 \amp 1 \end{bmatrix}, \qquad \begin{bmatrix} 1 \amp 4 \amp 0 \amp 3 \amp 0 \\ 0 \amp 0 \amp 1 \amp 5 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \amp 1 \end{bmatrix}, \qquad \begin{bmatrix} 1 \amp 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \amp 1 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{bmatrix}. \end{equation*}
    🔗
    🔗
    The order of the vectors in \(S\) matters! If you were to reorder \(S\) and then perform the above dependency analysis, you would potentially get a different \(S_0\) and different (but algebraically equivalent) dependency equations.
    🔗

    Example 5.1.5. Order Matters for Dependency Analysis.

    Consider vectors \(\vect{a}=\begin{bmatrix}1\\1\end{bmatrix}\text{,}\) \(\vect{b}=\begin{bmatrix}-1\\1\end{bmatrix}\text{,}\) and \(\vect{c}=\begin{bmatrix}0\\1\end{bmatrix}\text{.}\) If \(S = \{\vect{a},\vect{b},\vect{c}\}\text{,}\) then
    \begin{equation*} \rref(A_S)=\rref\left( \begin{bmatrix} 1 \amp -1 \amp 0 \\ 1 \amp 1 \amp 1 \end{bmatrix}\right) = \begin{bmatrix} 1 \amp 0 \amp 0.5 \\ 0 \amp 1 \amp 0.5 \end{bmatrix}, \end{equation*}
    and using Insight 5.1.3, we have the independent collection \(S_0=\{\vect{a},\vect{b}\}\) with dependency equation
    \begin{equation*} \vect{c} = 0.5\vect{a}+0.5\vect{b}. \end{equation*}
    On the other hand, if \(S = \{\vect{a},\vect{c},\vect{b}\}\text{,}\) then
    \begin{equation*} \rref(A_S)=\rref\left( \begin{bmatrix} 1 \amp 0 \amp -1 \\ 1 \amp 1 \amp 1 \end{bmatrix}\right) = \begin{bmatrix} 1 \amp 0 \amp -1 \\ 0 \amp 1 \amp 2 \end{bmatrix}, \end{equation*}
    and using Insight 5.1.3, we have the independent collection \(S_0=\{\vect{a},\vect{c}\}\) with dependency equation
    \begin{equation*} \vect{b} = -\vect{a}+2\vect{c}. \end{equation*}
    Order matters for dependency analysis!
    🔗
    🔗
    We now see that \(S\) is independent if and only if \(\rref\left([A \mid \vect{0}]\right)\) has no free variables, or in other words, every column of \(\rref(A_S)\) has a leading 1. We may then deduce the following proposition for quickly checking if \(S\) is independent.
    🔗

    Proposition 5.1.6. Computational Quick Check For Independence.

    If \(S=\{\vect{v}_1,\ldots \vect{v}_n\}\subset \mathbb{R}^m\text{,}\) then \(S\) is linearly independent if and only if \(\rref(A_S)\) has a leading 1 in every column.
    🔗
    🔗
    We now aggregate four established equivalent statements encoding independence.
    🔗

    Insight 5.1.7. Characterizations of Independence.

    If \(S=\{\vect{v}_1,\ldots, \vect{v}_n\}\subset \mathbb{R}^m\) and \(A=[\vect{v}_1 \mid \cdots \mid \vect{v}_n]\text{,}\) then the following are equivalent:
    🔗
    1. \(S\) is linearly independent.
      🔗
      🔗
    2. The matrix equation \(A\vect{x}=\vect{0}\) only has the trivial solution.
      🔗
      🔗
    3. \(\Null(A)=\{\vect{0}\}\text{.}\)
      🔗
      🔗
    4. \(\rref(A)\) has a leading 1 in every column.
      🔗
      🔗
    🔗

    Activity 5.1.8. Comparison of Number of Vectors to List-Length.

    Let \(S\subset \mathbb{R}^m\) be a collection of \(n\) vectors. Use Insight 5.1.3 to justify the statement:
    🔗
    If \(m < n\) (i.e., there are more columns than rows in \(A_S\)), then \(S\) must be dependent.
    🔗
    🔗
    Since a statement and its contrapositive are logically equivalent, you have also shown:
    🔗
    If \(S\) is independent, then \(m\ge n\text{.}\)
    🔗
    🔗
    Note that if \(m\ge n\text{,}\) \(S\) may or may not be independent, you need to check!
    🔗
    🔗

    Insight 5.1.9. Workflow to Determine Independence.

    You now have several strategies to determine if a collection of vectors is independent. I recommend the following workflow.
    🔗
    1. Separated
      If you see that the vectors are separated (Proposition 2.5.8), then you know the vectors are independent without needing to perform any computations.
      🔗
      🔗
    2. Columns > Rows
      If you see that the number of vectors is greater than the list-length of vectors, then you know the vectors are dependent without needing to perform any computations.
      🔗
      🔗
    3. Compute and Interpret \(\rref(A)\)
      Otherwise, you can perform Computational Quick Check Proposition 5.1.6 to deduce if the vectors are independent.
      🔗
      🔗
    🔗

    Example 5.1.10.

    Consider the collection \(S = \{\vect{v}_1,\vect{v}_2,\vect{v}_3\}\subset \mathbb{R}^2\) where
    \begin{equation*} \vect{v}_1=\begin{bmatrix}5\\1\end{bmatrix}, \quad \vect{v}_2=\begin{bmatrix}1\\3\end{bmatrix}, \quad \text{and} \quad \vect{v}_3=\begin{bmatrix}-2\\1\end{bmatrix}. \end{equation*}
    🔗
    Without doing any computations, since we see three vectors in \(\mathbb{R}^2\text{,}\) we know this collection is Dependent. Now, to find the dependency equations, we compute:
    \begin{equation*} \begin{bmatrix} 5 \amp 1 \amp -2 \\ 1 \amp 3 \amp 1 \end{bmatrix} \sim \begin{bmatrix} 1 \amp 0 \amp -0.5 \\ 0 \amp 1 \amp 0.5 \end{bmatrix}, \end{equation*}
    and using Insight 5.1.3,
    \begin{equation*} \vect{v}_3 = -0.5\vect{v}_1+0.5\vect{v}_2. \end{equation*}
    🔗
    🔗

    🔗
    To conclude this lesson, understanding the dependencies within a collection of vectors is a fundamental linear algebraic goal. Translating dependencies into matrix equations, we leveraged the computational tools of Gaussian elimination and rref to perform explicit Dependency Analysis (Insight 5.1.3). We hope you are now seeing that, while rref is a straightforward computation, it is how you interpret it in context that really matters.
