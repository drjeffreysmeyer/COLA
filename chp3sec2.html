    Lesson 3.2 Matrix Multiplication Sets

    Recall in Chapter Chapter 2, I introduced three fundamental sets associated to linear combination: span, null space, and solution set. Since matrix multiplication is a symbolic compactification of linear combination, it should not come as a surprise that these three mixture sets become matrix multiplication sets.
    🔗

    Subsection Span becomes Column Space

    The question of span concerns what all we can make with a fixed collection of ingredients. This notion is formalized with the concept of span (the noun) ( Definition 2.4.3). In symbols, if \(S=\{\vect{v}_1, \ldots, \vect{v}_n\}\subset \R^m\text{,}\) then \(\spn(S) = \{ x_1\vect{v}_1+\cdots+x_n\vect{v}_n \ | \ x_1,\ldots, x_n\in \R\}.\) If we use the definition of matrix multiplication (Definition 3.1.5) to compactify this expression and set \(A=[\vect{v}_1 \ | \ \cdots \ | \ \vect{v}_n]\text{,}\) then \(\spn(S) = \{ A\vect{x} \ | \ \vect{x}\in \R^n\}.\) We call this symbolic compactification the column space.
    🔗

    Definition 3.2.1. Column Space.

    If \(A=[\vect{v}_1 \ | \ \cdots \ | \ \vect{v}_n]\) is an \(m\times n\) matrix, then the column space of \(A\) is the span of its columns. In symbols,
    🔗
    \begin{equation*} \col(A) = \spn(\vect{v}_1, \ldots, \vect{v}_n) = \{A\vect{x} \ | \ \vect{x} \in \R^n\}. \end{equation*}
    🔗
    A rose by any other name... Do not be scared of column space, it is just different language for span (the noun) - something you already know! You may then ask: Why introduce two names for the same thing? It is simply a matter of convenience: if we start with matrix whose columns are not already symbolized, then it is convenient to directly reference and reason about its column space without having to first symbolize its columns.
    🔗
    Column spaces are another instance of subspace (cf. Definition 2.6.1). Remember, subspaces play a central role in linear algebra and it is always useful to be aware of which subsets we are working with happen to be subspaces.
    🔗
    Column Space is a Subspace. If \(A\) is an \(m\times n\) matrix, then \(\col(A)\) is a subspace in \(\R^m\text{.}\)
    🔗

    Proof.

    The justification of this proposition is a logical consequence of chaining together Definition 3.2.1 and Proposition 2.6.2.
    🔗
    🔗
    🔗

    Subsection Dependency becomes Null Space

    The question of redundancy concerns whether a collection of vectors contains one vector that can be made from a linear combination of the other vectors in the collection. This notion is formalized with the concept of dependence (Definition Definition 2.5.1). Algebraically, this condition was reformulated as asking if the zero vector can be made as a linear combination in a nontrivial way (cf. Proposition 2.5.9). Symbolically, if \(S=\{\vect{v}_1, \ldots, \vect{v}_n\}\subset \R^m\text{,}\) then we want to know if there exists numbers \(x_1,\ldots, x_n\in \R\text{,}\) at least one of which is not zero, such that \(x_1\vect{v}_1+\cdots+x_n\vect{v}_n=\vect{0}\text{.}\) If we use the definition of matrix multiplication (Definition 3.1.5) to compactify this expression and set \(A=[\vect{v}_1 \ | \ \cdots \ | \ \vect{v}_n]\text{,}\) then we want to know if there exists a nonzero vector \(\vect{x}\in \R^n\) such that \(A\vect{x}=\vect{0}\text{.}\) We call this symbolic compactification the null space.
    🔗

    Definition 3.2.2. Null Space.

    If \(A=[\vect{v}_1 \ | \ \cdots \ | \ \vect{v}_n]\) is an \(m\times n\) matrix, then the null space of \(A\) is the null space of its columns. In symbols,
    🔗
    \begin{equation*} \Null(A) = \Null(\vect{v}_1, \ldots, \vect{v}_n) = \{\vect{x}\in \mathbb{R}^n\ | \ A\vect{x}=\vect{0}\}. \end{equation*}
    🔗
    Null Space is a Subspace. If \(A\) is an \(m\times n\) matrix, then \(\Null(A)\) is a subspace in \(\R^n\text{.}\)
    🔗

    Proof.

    The justification of this proposition is primarily a logical consequence of chaining together Definition 3.2.2, Definition Definition 2.6.1, and Proposition 3.1.13. Alternatively, consider Proposition 2.6.3. Fill in the details on your own.
    🔗
    🔗
    Null space records redundancy. Do not be scared of null space, it is simply the null space of the columns of the matrix - something you already know! The null space is the set of all ways we can make the zero vector with the columns of our matrix.
    🔗

    Proposition 3.2.3. Dependency as nontrivial null space..

    If \(A\) is an \(m\times n\) matrix, then \(\Null(A)=\{\vect{0}\}\) if and only if the columns of \(A\) are independent.
    🔗
    🔗

    Proof.

    For this formal justification, try to re-interpret Proposition Proposition 2.5.9 using the compact notation of matrices and null space.
    🔗
    🔗

    Example 3.2.4. Finding Column Space and Null Space.

    Suppose \(A = \left[\begin{array}{rr}1 \amp 2\\2 \amp -1\\3 \amp 4\end{array}\right]\) and I want to know its column space \(\Col(A)\) and null space \(\Null(A)\text{.}\)
    🔗
    To start, I begin by recalling the meanings of these terms. Column space is the span of the columns of \(A\) and null space is all the ways I can make zero with the columns of \(A\text{.}\) So I then identify and write down the columns of \(A\text{:}\) \(S= \{\vect{v}_1,\vect{v}_2\} = \left\{\left[\begin{array}{r}1\\2\\3\end{array}\right], \left[\begin{array}{r}2\\-1\\4\end{array}\right]\right\}\text{.}\) I can see (e.g. by plotting) that \(\vect{v}_1\) and \(\vect{v}_2\) are non-collinear. Therefore, their span is the plane in \(\R^3\) going through the points \((0,0,0)\text{,}\) \((1,2,3)\text{,}\) and \((2,-1,4)\text{.}\) Furthermore, since \(S\) is non-collinear, it is independent, and hence the only way to make zero is the trivial way. Therefore the null space is the trivial (i.e. zero) subspace. In algebraic symbolism:
    🔗
    \begin{align*} \Col(A) \amp= \text{The plane in $\R^3$ with parametric vector form }\left\{x_1\left[\begin{array}{r}1\\2\\3\end{array}\right]+x_2\left[\begin{array}{r}2\\-1\\4\end{array}\right]\ \bigg |\ x_1,x_2\in \R\right\}.\\ \Null(A) \amp= \text{The trivial subspace }\{\vect{0}\}\subset\R^2. \end{align*}
    🔗

    Example 3.2.5. Finding Column Space and Null Space.

    Suppose \(B = \left[\begin{array}{rrr}1 \amp -1 \amp 0\\1 \amp 1 \amp 2\end{array}\right]\) and I want to know its column space \(\Col(B)\) and null space \(\Null(B)\text{.}\)
    🔗
    To start, I begin by recalling the meanings of these terms. Column space is the span of the columns of \(B\) and null space is all the ways I can make zero with the columns of \(B\text{.}\) So I then identify and write down the columns of \(B\text{:}\) \(S= \{\vect{w}_1,\vect{w}_2,\vect{w}_3\} = \left\{\left[\begin{array}{r}1\\1\end{array}\right],\left[\begin{array}{r}-1\\1\end{array}\right], \left[\begin{array}{r}0\\2\end{array}\right]\right\}\text{.}\) I can see (e.g. by plotting) that \(\vect{w}_1\) and \(\vect{w}_2\) are non-collinear. Therefore, their span is the whole plane in \(\R^2\text{,}\) and hence the span of \(S\) must also be all of \(\R^2\text{.}\) I can also see (e.g. by visual inspection), that \(\vect{w}_1+\vect{w}_2=\vect{w}_3\text{,}\) hence \(\vect{w}_1+\vect{w}_2-\vect{w}_3=\vect{0}\text{,}\) and thus I have null scalars \(\{1,1,-1\}\text{.}\) In algebraic symbolism:
    🔗
    \begin{align*} \Col(B) \amp= \spn(S) =\text{The whole plane }\R^2\\ \Null(B) \amp= \Null(S)=\text{The line in $\R^3$ with parametric vector form }\left\{t\left[\begin{array}{r}1\\1\\-1\end{array}\right] \ \bigg|\ t\in \R\right\}. \end{align*}
    🔗

    Subsection Makeability becomes Solution Set

    The question of makeability concerns whether a given vector \(\vect{b}\in \R^m\) can be made with the vectors in our collection, and if so, how. Symbolically, if \(S=\{\vect{v}_1, \ldots, \vect{v}_n\}\subset \R^m\text{,}\) then we want to know if there exists numbers \(x_1,\ldots, x_n\in \R\text{,}\) such that \(x_1\vect{v}_1+\cdots+x_n\vect{v}_n=\vect{b}\text{.}\) If we use the definition of matrix multiplication (Definition 3.1.5) to compactify this expression and set \(A=[\vect{v}_1 \ | \ \cdots \ | \ \vect{v}_n]\text{,}\) then we want to know if there exists a vector \(\vect{x}\in \R^n\) such that \(A\vect{x}=\vect{b}\text{.}\) We call this symbolic compactification the solution set of the matrix equation.
    🔗

    Definition 3.2.7. Solution Set.

    If \(A\) is an \(m\times n\) matrix and \(\vect{b}\in \R^m\text{,}\) then the solution set to the matrix equation \(A\vect{x}=\vect{b}\) is the collection of all vectors \(\vect{x}\in \R^n\) such that \(A\vect{x}=\vect{b}\text{.}\) In symbols,
    🔗
    \begin{equation*} \Sol(A,\vect{b}) = \{\vect{x}\in \R^n \ | \ A\vect{x}=\vect{b}\}. \end{equation*}
    🔗
    Solution sets to matrix equations are central to linear algebra, and we will revisit and look more deeply into them throughout the course.
    🔗
    Observe that \(\Sol(A,\vect{0})=\Null(A)\text{,}\) which is a subspace. On the other hand, if \(\vect{b}\ne \vect{0}\text{,}\) then \(\Sol(A,\vect{b})\) is never a subspace.
